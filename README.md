# 📚 Learning Platform

## 📖 Overview

The **Learning Platform** is a web-based educational application developed using **WordPress**, **PHP**, **MySQL**, and **PL/SQL**. The platform provides an interactive learning environment where students can access courses, complete quizzes, monitor their progress, and communicate with instructors. It is designed to simplify online education while providing an easy-to-use interface for learners and administrators.

The application leverages the flexibility of **WordPress** for content management, **PHP** for backend development, **MySQL** for database management, and **PL/SQL** for advanced database operations, reporting, and data processing.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ghkrknkp/Learning-platform.git
```

### Move Project

Copy the project folder into:

```
xampp/htdocs/
```

### Import Database

- Open phpMyAdmin
- Create a database named:

```
learning_platform
```

- Import

```
mysql_schema.sql
```

### Configure Database

Update

```
wp-config.php
```

or

```
config.php
```

with your database credentials.

### Start Server

Start

- Apache
- MySQL

using XAMPP.

Visit

```
http://localhost/Learning-platform
```
